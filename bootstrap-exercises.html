Exercise 2: Bootstrap Structure and Files

Exercise 2.1: Bootstrap Directory Structure

Bootstrap Directory Structure:

  • css/ - Contains compiled CSS files (bootstrap.min.css, bootstrap-grid.min.css)
  • js/ - Contains compiled JavaScript files for plugins (modals, dropdowns, tooltips)
  • scss/ - Source Sass files for customization
  • dist/ - Distribution files ready for production
Exercise 2.2: Bootstrap JavaScript Plugins

Bootstrap JavaScript bundle includes all plugins: Modals, Dropdowns, Tooltips, Popovers, Alerts, Buttons, Carousel, Collapse, Scrollspy, and Tab plugins.

Exercise 19: Customization with Sass

Exercise 19.1: Bootstrap Sass Setup
Bootstrap Sass Setup Instructions:
  1. Install Bootstrap: npm install bootstrap
  2. Create a _variables.scss file to override defaults
  3. Import Bootstrap in your main scss: @import "../node_modules/bootstrap/scss/bootstrap"
  4. Compile Sass to CSS using sass compiler
Exercise 19.2: Customized Variables

Variables that can be customized:

  • $primary: #007bff
  • $secondary: #6c757d
  • $success: #28a745
  • $border-radius: 0.25rem
  • $font-family-base: -apple-system, BlinkMacSystemFont
  • $grid-columns: 12
  • $grid-gutter-width: 1.5rem

Example _variables.scss:

$primary: #ff6b6b;
$secondary: #4ecdc4;
$border-radius: 0.5rem;
@import "../node_modules/bootstrap/scss/bootstrap";
